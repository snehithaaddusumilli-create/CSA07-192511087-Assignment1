# Task 11 – Defend the Network Design

Present and justify an end-to-end network design for the smart manufacturing plant.

Consider:
- Industrial Ethernet/fibre for fixed robot control and backbone.
- Managed switches, VLAN separation and QoS.
- Wi-Fi for office/non-critical devices.
- CCTV and local recording.
- Carrier WAN/fibre for the 400 km head-office link.
- AGV connectivity and suitable private 5G use.
- Error detection/recovery choices for time-critical and non-critical traffic.
- Numerical evidence from earlier tasks.
- At least two residual risks and mitigations.

**Add:** network diagram, calculations, design explanation and evidence.
